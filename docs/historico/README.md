# Histórico da documentação

Esta pasta preserva documentos antigos e versionados do OmniXML para manter rastreabilidade técnica sem misturá-los à documentação de consulta diária.

## Organização

- `fiscal/` — versões de SPED, EFD-Contribuições, PIS/COFINS, COFINS e Bloco M.
- `seguranca/` — fases de hardening e evolução da CSP/DOM/dependências.
- `hotfixes/` — correções pontuais registradas ao longo do desenvolvimento.
- `ux/` — decisões históricas de interface e experiência.

## Regra de uso

Para entender o comportamento atual, consultar primeiro os documentos da raiz de `docs/`, principalmente `FISCAL.md`, `SEGURANCA.md`, `ERS.md` e `ENGENHARIA.md`.

Os arquivos desta pasta devem ser usados quando for necessário reconstruir a evolução de uma decisão, investigar uma regressão ou consultar o contexto de uma versão específica.
